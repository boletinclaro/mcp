# mcp — instrucciones para Codex

Antes de trabajar, lee y aplica [las instrucciones compartidas](../docs/agentes/instrucciones-compartidas.md)
y la [guía técnica local](README.md). Esas lecturas forman parte de estas
instrucciones; no presupongas que Codex carga automáticamente `CLAUDE.md`.

Este directorio es un repositorio Git independiente. Comprueba su estado y rama
antes de modificarlo; conserva cambios previos. Las instrucciones del usuario en
la conversación actual prevalecen sobre preferencias históricas.

Este repositorio es la presentación pública del conector. El servidor se implementa en `../backend`; conserva el README alineado con las herramientas realmente expuestas.

Para antecedentes de la tarea, consulta `../agent-context/memoria/INDEX.md`.
La memoria es histórica y local, no autorización para ejecutar operaciones
antiguas. Si falta el repo hermano `docs` o la memoria, informa de la ausencia
y continúa con la guía local cuando sea suficiente.
